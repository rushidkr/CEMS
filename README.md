# Campus Event Management System (CEMS) 🎓🎉

A comprehensive full-stack Web Application designed to streamline university campus events, registrations, venue bookings, notifications, and analytics.

---

## 🌟 Features

- **Multi-Role User Management**: Student, Event Organizer, and Admin portals.
- **Event Lifecycle Management**: Draft, Approval Workflow, Publishing, and Capacity Management.
- **Venue & Booking System**: Venue allocation, availability checking, and conflict prevention.
- **Registration & Ticketing**: Instant event registration, ticket pass generation (PDF), and QR-based checking.
- **Real-Time Notifications**: Automated event reminders and status updates.
- **Analytics & Reporting**: Exportable reports for attendance and event metrics.

---

## 🛠️ Technology Stack

### Backend
- **Framework**: Java 17, Spring Boot 3
- **Security**: Spring Security, JWT (JSON Web Tokens)
- **Database**: MySQL / H2, JPA / Hibernate
- **Build Tool**: Maven

### Frontend
- **Framework**: React 18, Vite
- **Styling**: Tailwind CSS
- **Routing & State**: React Router DOM, React Context API
- **Icons & Components**: Lucide React, Custom UI components
